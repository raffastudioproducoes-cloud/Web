💻 Exemplo de Código

Criação de um turno com tRPC:

const { mutate: criarTurno } = trpc.turnos.criar.useMutation();

criarTurno({
  ganho: 250.50,
  km: 45,
  combustivel: 12
}, {
  onSuccess: (data) => {
    toast.success('Turno criado com sucesso!');
    queryClient.invalidateQueries(['turnos']);
  }
});

🚀 Como Começar

Clone o repositório e instale as dependências:

git clone <repository-url>
cd minharota-app
pnpm install
pnpm dev

O aplicativo estará disponível em http://localhost:3000
